# 星云有客

星云有客经营数据查询与分析的产品介绍页，包含经营场景说明与可搜索、筛选、复制的场景模板库。

## 本地预览

直接用浏览器打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000`。

## 发布到 GitHub Pages

仓库包含 `.github/workflows/pages.yml`。将项目推送到 GitHub 后，在仓库的 **Settings → Pages** 中把构建来源设为 **GitHub Actions**。此后推送到 `main` 分支会自动发布。

GitHub Pages 的访问范围遵循仓库和账号当前的 Pages 权限设置。若要公开访问，请先确认仓库的可见性符合预期。
